# SkillPilots Dashboard Demo

A responsive front-end recreation inspired by the SkillPilots dashboard screenshot supplied in the chat.

## Files
- `index.html` — dashboard structure and task implementation modal
- `style.css` — responsive layout, styling, and dark theme
- `script.js` — modal, reviewed confirmation, toast messages, and theme toggle

## Run the project
1. Extract the ZIP file.
2. Open the `SkillPilots_Project` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.

No installation or server is required.

## Notes
This is an academic front-end demo recreated from the screenshot. It is **not** the original SkillPilots website source code and does not include its private backend, database, login, or live submission services.
